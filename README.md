# Евродвушка 40,36 м² — дизайн-проект

Два варианта расстановки для сравнения:

| Вариант | Папка | Суть |
|---|---|---|
| **1** (зафиксирован) | корень и `v1/` | Линейная кухня, диван-перегородка, ТВ на простенке, стол Ø80 у окна. Шире проходы, больше шкафов. |
| **2** (по фото-референсам) | `v2/` | Г-образная кухня с колонной холодильника и пеналом, стол Ø90 на 4 места, диван 190 у окна, ТВ 50″ на новой стенке, ниша с банкеткой в прихожей, колонна со стиралкой в ванной, реечная стена в спальне. |

Ниже описан вариант 1; вариант 2 — в `v2/index.html`.

Проект квартиры по планировке застройщика (свободная планировка, Минск) и референсам: тёплый светлый беж, дуб, белый.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Весь проект на одной странице: план с мебелью, размерами, проходами и электрикой; 3D-модель с режимами «Обзор» и «Прогулка»; решения по комнатам; материалы; спецификация с моделями и ссылками; задание бригаде. Открыть в браузере (нужен интернет для three.js с cdnjs). |
| `plan.svg` | План расстановки отдельным файлом (печать, отправка бригаде). |
| `renders/*.jpg` | Виды из 3D-модели: сверху, кухня, гостиная, стол Жени, спальня, ПК-место, ванная, прихожая, лоджия. |

## Главные решения

- **Перегородка спальни** 100 мм по пунктиру застройщика, дверь 700 из прихожей.
- **Кухня-гостиная 3,10 × 5,15 м**: линейная кухня 3,10 м с холодильником Side-by-Side 91 см (LG GC-B257JLYV), посудомойкой 45, индукцией и духовкой; диван 160 спинкой к проходу; ТВ 43″ на простенке между окнами; круглый стол Ø80 у окна; стол Жени 100×60 (ANREX «Модерн») у перегородки.
- **Спальня 4,10 × 3,20 м**: кровать 160 с подъёмным механизмом (ANREX Sabrina 160, 171×214) изголовьем к южной стене, ТВ 43″ напротив, шкаф 140, ПК-место 140×60 (Mio Tesoro «Велия») с игровым креслом ThunderX3 у окна лоджии.
- **Прихожая**: шкаф-купе 120×61 (Пинскдрев «Глобус» П038.120) + шкаф 90×60, один грязезащитный коврик.
- **Ванная 1,72 × 2,60 м**: ванна 170×70 (Cersanit Lorena) со стеклянной шторкой, инсталляция Cersanit Delfi у стояка, столешница 105 см со стирально-сушильной машиной глубиной 45 см (Samsung WD806U2GAGD/LP) и раковиной.
- **Лоджия**: два кресла и столик, узкий шкаф.
- **Пол**: единый кварцвинил без порогов, под ежедневную уборку роботом-пылесосом.

## Перед заказом

Размеры сняты с плана по масштабу (±3–5 см). Перемерить: ширину ванной (под ванну 170 нужно ≥171 см), простенок между окнами (≥98 см под ТВ 43″), положение двери на лоджию, стояки и вентканал, высоту потолка. Цены в спецификации — ориентир; позиции с пометкой «найдено» подтверждены карточками магазинов, «типоразмер» — подобрать по наличию.
